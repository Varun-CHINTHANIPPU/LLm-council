# Capability matrix

| Capability | Status |
|---|---|
| General questions, explanations and task assistance | Supported (model output, unverified) |
| Coding guidance, troubleshooting and comparative analysis | Supported by task-agnostic prompts |
| Creative writing, rewriting and brainstorming | Supported by task-agnostic prompts |
| Two UTF-8 input files and stable answer output | Implemented |
| Executable `./start` launcher | Implemented |
| Automatic ordinary-answer vs. numbered-document routing | Implemented |
| Parallel multi-model proposals | Implemented |
| Cross-family review, judge synthesis, independent model audit | Implemented when providers are available |
| Long-form section drafting, continuation, assembly and review | Implemented |
| Fast/thorough depth, deadlines, hedging and circuit breaker | Implemented |
| Per-stage timings and offline run replay | Implemented |
| Compatibility with historic research-oriented saved runs | Retained |
| Independent verification of real-world facts | Not included |
| Running generated code or externally checking citations | Not included |
| Formal proof or mathematical correctness guarantee | Not included |
| Guaranteed availability of free-tier providers | Not claimed |

Historical `eval/` fixtures and some JSON names use older research wording.
These are retained for backward compatibility; they do not constrain the
types of tasks that the main Council can answer.
